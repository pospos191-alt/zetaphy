What the contract allows

  • ERC-20 token "Chip" (CHIP), total supply 10,000,000,000. Name and symbol are shown as written in the contract; Neuro does not confirm them.
  • Upgradeable: the admin (0xaa93f045b057ac64f79ae3f7d115cd3880e854d9) can replace all of the code at any time. What is checked today may not hold tomorrow.
  • Can block specific wallets (isBlacklisted(address)). A blocked wallet may be unable to sell or transfer.
  • Public source code that Sourcify confirmed matches the on-chain code byte for byte (Chip, Solidity, 0.8.33+commit.64118f21). Read it at https://repo.sourcify.dev/42161/0x13ae0c66dd063fbd6ba12ec1a1d5d07343daa03f
  • A simulated buy and sell of a small amount through Uniswap V2 worked (tax: 0% buy, 0% sell). This is a test at the current block only: whoever controls the contract may still raise the tax or block selling later.
  • Only 1.2% of the Uniswap V2 pool's liquidity tokens are burned. The rest is held elsewhere, in a lock contract or a wallet (Neuro does not check which); whoever holds it can withdraw that liquidity.
  • Checked from on-chain code with fixed rules. Powers hidden behind unusual function names can be missed. Not investment advice.
