# ZETAPHY mainnet: ประกาศความเสี่ยง

ZETAPHY mainnet (`zetaphy_3659-1`, EVM chain id 3659, เหรียญ ZTPHY) มีเวลาเริ่มเชน (genesis) **13 พฤศจิกายน 2026 เวลา 14:00 UTC
(21:00 น. เวลาไทย)** genesis sha256 คือ `ca0efb15f6ca80f57e157b32837e012a15f3dc3597531b18747629c8f0a94667`
([ไฟล์ที่เผยแพร่](../zetaphy-chain/mainnet/zetaphy_3659-1/README.th.md))

เจ้าของโครงการตัดสินใจเปิดเชนตอนนี้ โปรดอ่านว่าการตัดสินใจนี้หมายถึงอะไร ก่อนถือหรือส่ง ZTPHY

## สิ่งที่ต้องรู้

1. **มี validator ตัวเดียว ดูแลโดยโครงการ** เชนทำงานบน validator ตัวเดียวที่โครงการ ZETAPHY ดูแลเอง ใครคุมเครื่องนั้น
   หรือกุญแจของมันได้ จะหยุดเชน ปิดกั้นธุรกรรม และถ้าใช้ binary ที่ดัดแปลง ก็เปลี่ยนกฎของเชนได้ รวมถึงปิดระบบป้องกันทุกตัว
   ถ้าเครื่องนั้นเสีย เชนจะหยุดจนกว่าจะกู้คืน มีแผนเพิ่ม validator อิสระ แต่ยังไม่มีใครเข้าร่วม
2. **ยังไม่มี audit จากภายนอกที่เป็นอิสระ** โค้ดผ่านแค่การตรวจภายใน ยังไม่มีบริษัท audit หรือการแข่งขัน audit สาธารณะตรวจ
   release ที่ใช้รัน mainnet
3. **ทดสอบสั้นกว่าที่วางแผนไว้** release นี้รันบน testnet ไม่ถึง 4 สัปดาห์ตามที่ [runbook](ZETAPHY-MAINNET-RUNBOOK.th.md) กำหนด
4. **กุญแจ multisig ตอนนี้อยู่กับคนคนเดียว** กองเหรียญ (รางวัล, airdrop, ชุมชน, สภาพคล่อง, ทีม) และผู้มีสิทธิ์สั่ง
   circuit-breaker เป็น multisig แบบ 2 จาก 3 แต่กุญแจทั้ง 3 ดอกอยู่กับเจ้าของโครงการ multisig จึงกันได้แค่กรณีกุญแจหาย 1 ดอก
   ไม่ได้กันเจ้าของโครงการเอง มีแผนย้ายกองเหรียญไป multisig ที่กุญแจอยู่กับคนละคน
5. **การโหวต governance ใช้เวลา 1 วัน** proposal ผ่านได้ภายใน 24 ชั่วโมงหลังเริ่มโหวต (แบบเร่งด่วน 12 ชั่วโมง) ถ้าถือ ZTPHY
   ควรติดตาม proposal รัฐธรรมนูญของเชน (ทำงานตั้งแต่บล็อกแรก) ไม่ยอมรับ proposal ที่ย่นเวลาโหวต สร้างเหรียญเพิ่ม
   หรือลดค่าขั้นต่ำอื่น ๆ
6. **ยังไม่เปิดให้เข้าถึงจากภายนอก** ตอนเริ่มเชนยังไม่มี RPC หรือ peer สาธารณะ จนกว่าจะประกาศไว้ใน
   [โฟลเดอร์ genesis](../zetaphy-chain/mainnet/zetaphy_3659-1/README.th.md) "RPC ของ ZETAPHY mainnet" ที่เห็นจากที่อื่นไม่ได้มาจากโครงการ
7. **Airdrop ยังไม่เปิด** airdrop ของผู้ถือ SWD เป็นแบบให้ผู้รับมากดรับเอง และยังไม่เริ่ม address ของสัญญาจะประกาศใน repo นี้
   โครงการไม่เคยขอคำกู้กระเป๋า (recovery phrase), private key หรือให้จ่ายเงินเพื่อรับ airdrop
8. **Bridge ยังปิดอยู่** Saphan bridge และสัญญาอื่น ๆ ยังไม่ได้ deploy บน mainnet

**ใช้ ZETAPHY mainnet เฉพาะจำนวนที่ยอมเสียได้เท่านั้น**

## สิ่งที่ล็อกไว้ตั้งแต่บล็อกแรก

- จำนวนเหรียญ: 1,000,000,000 ZTPHY ไม่มีการผลิตเพิ่ม ค่าธรรมเนียมครึ่งหนึ่งและ address dEaD ถูกเผาทิ้ง
- เหรียญของทีม: ล็อก 1 ปี แล้วทยอยปลดจนครบปีที่ 4
- chain guard, shield, invariant firewall, security core และรัฐธรรมนูญ ทำงานอยู่
- กุญแจดอกเดียวสั่ง circuit-breaker ไม่ได้ ต้องเป็น governance หรือ multisig circuit-breaker แบบ 2 จาก 3 เท่านั้น
