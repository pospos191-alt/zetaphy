# ชุดประกาศ ZETAPHY (launch kit)

ข้อความพร้อมคัดลอกทุกช่องทางอยู่ใน [LAUNCH-KIT.md](LAUNCH-KIT.md) ส่วนข้อความภาษาไทยสำหรับกลุ่มคนไทยอยู่ในหัวข้อ 6 ของไฟล์นั้น
เจ้าของโครงการเป็นคนโพสต์เอง ไม่มีอะไรถูกโพสต์อัตโนมัติ

**ข้อเท็จจริงที่ใช้ได้ (และห้ามเกินจากนี้):**
- testnet (Cosmos SDK + EVM): chain ID 77390 / `zetaphy_77390-1`
- ลายเซ็น ML-DSA-44 (FIPS 204), ใบรับรอง finality แบบ post-quantum และบัญชีที่รับเฉพาะ key แบบ post-quantum
- AI 35 ฟีเจอร์ (Neuro) รันในเบราว์เซอร์ ไม่ต้องใช้การ์ดจอ
- บริดจ์ Saphan
- firewall ในโหนด

**ต้องเขียนกำกับทุกครั้ง:** เป็น testnet, เหรียญไม่มีมูลค่า, ยังไม่ผ่าน audit จากภายนอก

## ก่อนโพสต์ (เช็กให้ครบ)
- เปิด `https://rpc.sawasdeecoin.com/rpc/status` ในเบราว์เซอร์แล้วได้คำตอบ (RPC สาธารณะจะหยุดเมื่อ VM ใกล้เต็มโควตาเน็ตฟรีของเดือน และเปิดคืนวันที่ 1)
- หน้า app.sawasdeecoin.com แสดงเลขบล็อกล่าสุด ไม่ใช่ "–"
- ปุ่ม "เพิ่มเครือข่าย" ใน MetaMask ใช้ได้ และ faucet ส่งเหรียญทดลองได้
- ควรโพสต์ช่วงต้นเดือน เพราะคนยิ่งเยอะ RPC ยิ่งส่งข้อมูลออกมาก
