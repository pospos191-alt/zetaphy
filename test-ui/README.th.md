# เว็บแอป SWD AMM (`test-ui/`)

เปิดใช้ที่ **https://swd-amm.sawasdeecoin.com/** (โปรเจกต์ Vercel ชื่อ `test-ui` โฟลเดอร์ `test-ui/`)
English: [README.md](README.md)

## แอปนี้คืออะไร

หน้าเว็บสำหรับใช้งานโปรแกรม SWD AMM บน Solana: แลกเหรียญ (swap) เพิ่ม/ถอนสภาพคล่อง และดูโพซิชันของคุณ
ในพูล 3 แบบ (constant-product, DLMM, SWDMM v2) มีกราฟราคา ตัวช่วยคำสั่งจำกัดราคา/DCA และปุ่มขอ SOL ทดสอบ
หน้าเว็บคุยกับบล็อกเชนโดยตรงจากเบราว์เซอร์

ตอนนี้ใช้งานบน **devnet** (เหรียญทดสอบ ไม่มีมูลค่าจริง) — **mainnet ยังปิดอยู่** จนกว่าโปรแกรมจะผ่านการตรวจสอบ
ความปลอดภัย (audit) จากผู้ตรวจอิสระ และ deploy ขึ้น mainnet แล้ว

สิ่งที่ช่วยให้ผู้ใช้ปลอดภัย:
- **ป้ายเครือข่าย + แถบเตือน** บอกว่าอยู่เครือข่ายไหน (devnet = "เหรียญทดสอบ ไม่มีมูลค่าจริง")
- **ตรวจสอบแอปนี้** (ไอคอนโล่ด้านบน / ลิงก์ในแถบเตือน / ท้ายหน้า): อ่านจากบล็อกเชนว่าใครแก้โปรแกรมได้
  (ล็อกถาวร / multisig ของ Squads / กุญแจคนเดียว) ลายนิ้วมือโปรแกรม (SHA-256) security.txt
  การหยุดสร้างพูล เวลารอของ governance และสถานะ audit
- **ตรวจความปลอดภัยของเหรียญ** ผ่าน SWD Audit API แสดงระดับความเสี่ยงใต้ฟอร์ม swap/สร้างพูล และก่อนเซ็น
  ถ้า API ล่มก็แค่แจ้งว่าใช้ไม่ได้ ไม่ขวางการใช้งาน
- **สรุปก่อนเซ็น**: จำนวนที่จ่าย ยอดที่น่าจะได้ ยอดขั้นต่ำ ค่าธรรมเนียม ผลกระทบต่อราคา เครือข่าย
- ข้อผิดพลาดของโปรแกรมแสดงเป็นภาษาคน (ครบทั้ง 93 รหัส)
- 8 ภาษา: ไทย อังกฤษ จีน ญี่ปุ่น เกาหลี เวียดนาม สเปน รัสเซีย

## วิธีเปลี่ยนไป mainnet (ทำทีหลัง)

ทำตามลำดับ และทำต่อเมื่อข้อก่อนหน้าเสร็จแล้วเท่านั้น:

1. **Audit**: จ้างผู้ตรวจอิสระ ให้ผ่าน และเผยแพร่รายงาน (ดู `docs/DEFI_LISTING.th.md`, `docs/MAINNET_RUNBOOK.md`)
2. **Deploy** ด้วย `scripts/deploy-mainnet.sh` (ลอง dry run ก่อน แล้วค่อยใส่ `--execute`; ตอนนี้ไฟล์อยู่ใน branch
   `claude/defi-listing` จนกว่าจะ merge) สคริปต์จะพิมพ์ **program id ของ mainnet** ออกมา และขั้น `handover`
   จะโอนสิทธิ์แก้โปรแกรมไปให้ **Squads vault**
3. แก้ไฟล์ **`test-ui/config.js`** ส่วน `mainnet` (ช่องที่ต้องใส่):
   - `enabled: true`
   - `rpc: "https://..."` — URL ของ RPC mainnet ที่ใช้จากเบราว์เซอร์ได้ (เช่น Helius / Triton / QuickNode)
     URL นี้ทุกคนเห็นได้ ให้ตั้งในหน้าผู้ให้บริการว่าใช้ได้เฉพาะโดเมน `swd-amm.sawasdeecoin.com`
     (อย่าใช้ `api.mainnet-beta.solana.com` เพราะจำกัดจำนวนครั้ง)
   - `programId: "..."` — program id ของ mainnet จากข้อ 2 (**ไม่ใช่** id ของ devnet)
   - `squadsMultisig: "..."` — บัญชี multisig ของ Squads (ไม่ใช่ vault), `squadsVaultIndex: 0`
   - และใน `PROJECT.audit`: `status: "passed"`, `auditor: "<ชื่อบริษัท>"`, `reportUrl: "https://..."`,
     `programSha256: "<sha256 ของไฟล์ .so ที่ผ่าน audit>"`

   เมนูเครือข่ายจะมี Mainnet ให้เลือกก็ต่อเมื่อ `enabled` เป็น true **และ** ใส่ `programId` กับ `rpc` แล้วเท่านั้น
4. commit → push → merge แล้ว Vercel จะ deploy ใหม่เอง (เมื่อบัญชี Vercel ของทีมกลับมาใช้งานได้ ตอนนี้ติด 402)
5. เปิดเว็บ เลือก **Mainnet** กด **ตรวจสอบแอปนี้** ต้องเห็นว่า "ใครแก้ไขโปรแกรมได้" = multisig vault ของ Squads
   และลายนิ้วมือโปรแกรม "ตรงกับเวอร์ชันที่ผ่าน audit"

## สิ่งที่เจ้าของโปรเจกต์ต้องทำ (สรุป)

1. จ้างและผ่าน **audit** อิสระ
2. รัน `scripts/deploy-mainnet.sh` (ให้คนที่ทำเป็นช่วย; เก็บไฟล์กุญแจไว้ในเครื่องตัวเองเท่านั้น ห้ามส่งให้ใคร)
3. ใส่ค่าใน `test-ui/config.js` ตามข้อ 3 ด้านบน
4. ให้ Vercel deploy ใหม่ (ต้องจ่ายบิล Vercel ที่ค้างก่อน)
