# jupiter-amm-swd — ชุดเชื่อม SWD AMM เข้ากับ Jupiter

Jupiter (jup.ag) คือตัวรวมราคา (aggregator) ที่คนบน Solana ใช้แลกเหรียญมากที่สุด
ถ้า Jupiter "ต่อ" กับ SWD AMM ได้ คนที่แลกเหรียญผ่าน Jupiter จะถูกส่งคำสั่งมาที่ pool ของเราโดยอัตโนมัติ
เมื่อเราให้ราคาดีที่สุด → มี volume จริง ซึ่งเป็นตัวเลขที่ Solscan / DefiLlama ดู

โฟลเดอร์นี้คือ **SDK (โค้ด Rust)** ที่ Jupiter ขอจาก DEX ทุกเจ้า: มันบอก Jupiter ว่า
"ถ้าแลก X เหรียญใน pool นี้ จะได้กี่เหรียญ" (quote) และ "ต้องส่งบัญชีอะไรบ้างไปที่โปรแกรม" (account metas)
เวอร์ชันภาษาอังกฤษพร้อมรายละเอียดทางเทคนิค: [README.md](README.md)

## สถานะ

- เขียนตาม `jupiter-amm-interface` **0.6.1** (เวอร์ชันเสถียรล่าสุด ณ 8 พ.ย. 2026; มี 1.0.0-beta ด้วย ย้ายไปได้ง่าย)
- รองรับ pool แบบ **SWDMM v2** (แบบที่หน้าเว็บใช้สร้าง pool) — ยังไม่รองรับ pool แบบ CP เดิม และ DLMM
- **ตัวเลขตรงกับโปรแกรมจริงทุกหน่วย:** ไฟล์คณิตศาสตร์ไม่ใช่สำเนา แต่ดึงไฟล์ `swdmm_math.rs` ของโปรแกรมมาคอมไพล์ตรง ๆ
  และมีเทสต์ที่รันโปรแกรม `.so` ตัวจริงในเครื่องจำลอง (LiteSVM) 400 กรณี: 339 swap ได้ผลตรงกับ quote ทุกหน่วย,
  61 กรณีที่ quote บอกว่าทำไม่ได้ โปรแกรมจริงก็ปฏิเสธเหมือนกัน
- ยังส่งให้ Jupiter ไม่ได้ จนกว่าโปรแกรมจะ **ผ่าน audit และ deploy บน mainnet**

## รันเทสต์ (สำหรับนักพัฒนา)

```bash
anchor build                     # ที่ root ของ repo (เพื่อให้มีไฟล์ .so สำหรับเทสต์ on-chain)
cd integrations/jupiter-amm-swd
cargo test
```

## สิ่งที่ Jupiter ต้องทำฝั่งเขา (เราทำแทนไม่ได้)

1. เพิ่มชื่อ SWD AMM เข้าไปใน `Swap` enum ของเขา และเขียนตัวเรียกโปรแกรมของเราใน router
   (ตอนนี้โค้ดเราใส่ค่าชั่วคราว `PLACEHOLDER_SWAP` ไว้)
2. ตรวจว่าบัญชีเหรียญปลายทางของ router เป็นของผู้เซ็นคนเดียวกันหรือไม่ — โปรแกรมเราบังคับให้ทั้งบัญชีต้นทางและปลายทาง
   เป็นของผู้เซ็น ถ้า router ของ Jupiter ไม่ทำแบบนั้น ต้องแก้โปรแกรมเล็กน้อย (**ควรถามใน audit / ถาม Jupiter ก่อน deploy**)

## ขั้นตอนของเจ้าของโปรเจกต์ (หลัง audit + mainnet)

1. แก้ `SWD_AMM_PROGRAM_ID` ใน `src/lib.rs` เป็น program id ของ mainnet (ไม่บังคับ — SDK อ่าน id จากเจ้าของบัญชี pool อยู่แล้ว)
2. สร้าง pool แรก ๆ และใส่สภาพคล่อง (อย่างน้อยเกินขั้นต่ำของ Jupiter ต่อ pool)
3. ติดต่อ Jupiter ผ่านช่องทางในหน้า DEX Integration ส่ง: ลิงก์ repo นี้ (โฟลเดอร์ `integrations/jupiter-amm-swd`),
   ลิงก์รายงาน audit, program id, หน้า "Verified" บน Solscan, ตัวเลข TVL/volume
4. ตอบคำถามของทีม Jupiter (ให้นักพัฒนาช่วยตอบเรื่องเทคนิค)

ไม่ต้องให้ private key กับใครทั้งสิ้นในขั้นตอนนี้
